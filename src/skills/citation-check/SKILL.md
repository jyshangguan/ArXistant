---
name: citation-check
description: Check manuscript citations for internal consistency, bibliographic accuracy, and evidence supporting particular claims, with explicit uncertainty.
---
Separate internal reference matching, public bibliographic metadata verification, and claim support. Use only supplied retrieved evidence IDs. A title, DOI, search result, or abstract is not proof of full-text claim support. Identify metadata-only and abstract-only checks. If sources are unavailable state unverified or needs author check, never infer an error merely from no search match. A cited work absent from the supplied reference excerpt is not established as missing from the manuscript's reference list: report it as not verifiable in the supplied excerpt. Suggested replacement references require retrieved evidence.
For lookup, extract minimal public bibliographic queries (author/year/title/identifier), never unpublished manuscript sentences. Prefer ADS/SciX for astronomy. Avoid requirements such as a DOI for every reference type. Journal rules need a verified source; otherwise present them as general consistency suggestions.
