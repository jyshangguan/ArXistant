name: figure-table-review
description: Inspect manuscript figure and table presentation, labels, captions, and consistency using page images and surrounding text.
---
When page images are supplied, inspect labels, axes, units, legends, panel numbers, typography, clipping, readability, accessible color/line distinctions, and consistency with captions and discussion. Compare across figures when supporting images are supplied. Text-only input allows caption/cross-reference checks only; explicitly mark visual checks unavailable.
Use exact caption quotes or a page note as anchors. Do not infer original asset resolution or production compliance from a rendered page. Scientific disagreements require evidence; visual appearance alone cannot verify results. Preserve the user's figure conventions unless they impair clarity or conflict with a verified journal rule.
