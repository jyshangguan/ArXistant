Review every supplied target block for the requested categories. Identify grammar errors, ambiguous wording, undefined acronyms, terminology and notation inconsistencies, and unclear structure. Distinguish errors from optional style preferences. Avoid rewording sound prose merely to generate feedback.
Each finding needs category, severity, page, supplied block_id, exact quote, specific comment, optional suggested replacement, and evidence IDs when applicable. For figure-wide observations identify the supplied page and leave quote empty if no text is an accurate anchor. Do not claim sources were verified without retrieved evidence. Do not infer target-journal rules from the template. Do not repeat findings already provided as context unless new evidence changes the assessment.
